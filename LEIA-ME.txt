PDV AÇAÍ OBRIGATÓRIO — V6.10.31 CORRIGIDO (AMBIENTE DE TESTES)

ARQUIVOS
- index.html
- sw.js (service worker original, agora integrado ao Firebase Messaging)
- manifest.webmanifest
- apple-touch-icon.png
- icon-192.png
- icon-512.png

INSTALAÇÃO
1. Faça backup do conteúdo atual do repositório de TESTES.
2. Extraia este ZIP e envie todos os arquivos para a raiz do repositório de TESTES, substituindo os arquivos correspondentes.
3. Apague do repositório de testes o arquivo antigo firebase-messaging-sw.js, se ele tiver sido enviado na tentativa anterior; esta versão usa somente sw.js.
4. Não publique no repositório de produção.
5. Abra o GitHub Pages por HTTPS. No iPhone, abra no Safari, adicione à Tela de Início e abra o app instalado.
6. No painel do PDV, use o botão de teste de notificações. Ele solicita permissão, registra o service worker existente, tenta gerar o token FCM e envia uma notificação local de teste.

CORREÇÕES DESTA VERSÃO
- Firebase foi colocado no fim real do HTML, fora dos templates de impressão e dos scripts existentes.
- O Firebase reutiliza o service worker sw.js do PDV; não registra um segundo worker na mesma raiz.
- O botão já existente de teste de notificações foi preservado; não foi criado um botão flutuante duplicado.
- Layout, telas, navegação, URL centralizada do Apps Script e dados locais vieram do pacote V6.10.31 MENU_POPUPS_TESTE.
- Nenhuma alteração foi feita no Apps Script ou na planilha.

LIMITES
- Esta entrega gera o token FCM no dispositivo e o mantém localmente para a próxima etapa. O token também aparece no console do navegador para diagnóstico.
- O envio remoto entre dispositivos ainda depende de endpoint/backend seguro e não está implementado aqui.
- Encomendas e demais recursos já existentes no pacote-base foram preservados; este pacote não altera a lógica do Apps Script.

SEGURANÇA FIREBASE / GITHUB
- A configuração Firebase de cliente e a chave VAPID pública são identificadores/chaves públicas usadas no navegador; não são uma chave privada de servidor.
- Nunca publique service account JSON, private_key, credenciais de servidor ou chave privada VAPID.
- Confira o tipo exato do alerta em GitHub > Security > Secret scanning > Secret scanning alerts. Se for uma credencial privada real, revogue/rotacione imediatamente. Se for a API key do Firebase, restrinja-a no Google Cloud por HTTP referrers (domínio do GitHub Pages de testes e domínio de produção quando aplicável) e por APIs necessárias; não trate a VAPID pública como segredo.
